Communauté

Un espace pour échanger, challenger, améliorer et versionner les BOX.

Pourquoi rejoindre ?

Le moteur d'Alliance Sim

La communauté est le moteur d'Alliance Sim : chaque BOX est une « release » améliorable. Nous collectons les retours terrain (matériaux, durabilité, réalisme, pédagogie), puis nous publions des versions documentées (BOM, schémas, SOP, médiathèque).

Cette méthode favorise l'apprentissage structuré et l'amélioration continue.

Public éligible : professionnels de santé impliqués en endoscopie digestive (médecins, IDE, équipes biomédicales). L'inscription implique l'acceptation de la charte communautaire.

WhatsApp

Rejoindre le groupe WhatsApp

Le groupe WhatsApp est le canal principal d'échanges rapides : partage de photos terrain, questions de construction, retours d'expérience sessions.

Règles d'usage :
  • Pas de données patient identifiantes.
  • Les administrateurs modèrent/suppriment selon la charte.
  • Canal d'entraide formation uniquement (pas de validation médico-légale).

Vous pouvez inviter des membres via lien d'invitation ou code QR depuis WhatsApp (fonction native).

Gouvernance

Politique de modération

Nous appliquons un code de conduite inspiré du Contributor Covenant (version française) : respect, inclusion, procédures de signalement, et sanctions graduées.

Rôle Responsabilités
Product Owner Priorise le backlog (pages, docs, médias), valide les releases.
Référent hygiène/qualité Valide la page retraitement/SOP (conformité DGOS/ESGE).
Maintainers BOX (1/BOX) Triage issues, review PR, release notes.
Modérateurs communauté Règles WhatsApp, gestion des incidents.
